We need to create a website that users can use as personal diary.
The website should be able to:
- Users can create an account and login to the website.
- Users can create a new diary entry.
- Users can view their diary entries.
- Users can edit their diary entries.
- Users can delete their diary entries.
- Users can search for their diary entries.
- Users can filter their diary entries.
- Users can sort their diary entries.
- Users can export their diary entries.
- Users can import their diary entries.
- Users can share their diary entries with other users.
